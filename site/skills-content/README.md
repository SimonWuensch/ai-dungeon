# Skills-Content

Unveränderte Kopien der Skill-Quellen aus [mattpocock/skills](https://github.com/mattpocock/skills)
(MIT-lizenziert, siehe `THIRD_PARTY_LICENSES.md` im Repo-Root) — getrennt von `.claude/skills/`, das
die aktive, von Claude Code genutzte Kopie ist.

**Zweck dieses Ordners:**
1. Basis für zukünftige Anpassung der Skill-Inhalte an unsere eigenen Usecases.
2. Zukünftige Quelle für Skill-Detailseiten in der Web-UI mit vollständigem (nicht zusammengefasstem)
   Inhalt — bisher zeigt `docs/skills/*.mdx` nur kuratierte Zusammenfassungen.

Liegt bewusst außerhalb von `docs/`, damit nichts davon automatisch im Sidebar/in der Navigation
auftaucht — noch ist hier nichts mit der Web-UI verdrahtet.

## Struktur

- `engineering/` — die 18 Engineering-Skills aus `skills/engineering/` der Quelle.
