# Skills lokal in IntelliJ einrichten

## Was ist das?

Eine einmalige Einrichtung pro Rechner (plus ein kleiner Schritt pro Projekt), damit du in **jedem**
Projekt einfach `/tdd`, `/grill-with-docs`, `/implement` usw. schreiben kannst, und der Chat den
passenden Skill aus einem zentralen Ordner nachlädt, statt dass du den Inhalt jedes Mal von Hand
reinkopierst.

## Wie funktioniert das?

Drei Teile greifen ineinander:

1. **Ein zentraler Skill-Ordner** auf deinem Rechner (z.B. `C:\dev\ai\skills`), einmal befüllt mit
   den heruntergeladenen Skill-Dateien.
2. **Ein Junction-Link `.ai-skills`** im Root jedes Projekts, der auf diesen zentralen Ordner zeigt.
   Kein echter Ordner, nur ein Verweis, deshalb reicht es, den zentralen Ordner an einer Stelle zu
   pflegen.
3. **Eine feste Chat-Anweisung** in IntelliJ (gilt für jede neue Chat-Sitzung, in jedem Projekt), die
   der KI sagt: sobald eine Nachricht mit `/<name>` beginnt, lies `.ai-skills/<name>.md` im
   Projekt-Root und folge dem, was dort steht.

## Einmalige Einrichtung

### 1. Zentralen Ordner anlegen und befüllen

Einen Ordner an einer festen Stelle anlegen (z.B. `C:\dev\ai\skills`), dann alle 17 Skills dort
hinein entpacken:

<DownloadAllButton />

### 2. Pro Projekt: `.ai-skills` verlinken

Im Projekt-Root, in der Kommandozeile (kein Administrator nötig, Junctions brauchen keine erhöhten
Rechte):

```
mklink /J .ai-skills C:\dev\ai\skills
```

`.ai-skills` gehört in die `.gitignore` (lokal oder projektweit): es ist ein persönlicher Verweis
auf deinen Rechner, kein Repo-Inhalt, den andere mitbekommen sollen.

### 3. Chat Instructions in IntelliJ setzen

**Settings → Tools → AI Assistant → Prompt Library → Chat Instructions**, folgenden Text einfügen:

```
Wenn meine Nachricht mit "/" beginnt, gefolgt von einem Namen ohne Leerzeichen (z.B. "/tdd", "/grill-with-docs"):
1. Lies die Datei ".ai-skills/<name>.md" im Projekt-Root.
2. Existiert sie: folge ab jetzt den Anweisungen darin, für den Rest dieser Antwort und des weiteren Gesprächs, bis ein anderer "/name" aufgerufen wird.
3. Existiert sie nicht: sag das explizit ("Kein Skill '<name>' in .ai-skills gefunden") und liste, falls der Ordner ".ai-skills" existiert, die dort vorhandenen Skills auf (Dateinamen ohne ".md").
Nachrichten, die nicht mit "/" beginnen, beantworte ganz normal.
```

Das gilt IDE-weit, für jedes Projekt, das du in dieser IntelliJ-Installation öffnest, nicht nur für
eines.

## Skills aktualisieren

Neue oder geänderte Skills laden sich alle über denselben ZIP-Download nach: alten Inhalt im
zentralen Ordner überschreiben, fertig. Kein erneuter Symlink nötig, der zeigt schon auf den
richtigen Ort.

## Für Kollegen

Diese drei Schritte gelten pro Rechner, nicht pro Projekt: einmal einrichten, danach funktioniert
`/<skill>` in jedem Projekt, das einen `.ai-skills`-Junction bekommt. Wer mitmachen will, braucht
nur den ZIP-Download, den `mklink /J`-Befehl im jeweiligen Projekt-Root, und die Chat Instructions
oben, einmalig in den eigenen IntelliJ-Einstellungen.
