# Skills lokal in IntelliJ einrichten

## Was ist das?

Eine einmalige Einrichtung pro Rechner (plus ein kleiner Schritt pro Projekt), damit du in **jedem**
Projekt schnell auf einen Skill zugreifen kannst, statt seinen Inhalt jedes Mal von Hand
reinzukopieren.

## Wie funktioniert das?

Zwei Teile greifen ineinander:

1. **Ein zentraler Skill-Ordner** auf deinem Rechner (z.B. `C:\dev\ai\skills`), einmal befüllt mit
   den heruntergeladenen Skills. Jeder Skill liegt darin als eigener Unterordner mit einer
   `SKILL.md`, z.B. `C:\dev\ai\skills\wizard\SKILL.md`, das ZIP unten ist schon so aufgebaut.
2. **Ein Junction-Link `.ai-skills`** im Root jedes Projekts, der auf diesen zentralen Ordner zeigt.
   Kein echter Ordner, nur ein Verweis, deshalb reicht es, den zentralen Ordner an einer Stelle zu
   pflegen.

Im Chat rufst du einen Skill dann direkt über die `#`-Referenz auf: `#` tippen, den passenden
Skill-Ordner aus `.ai-skills` auswählen, danach deine eigentliche Frage oder Anweisung dazuschreiben.
Kein Chat-Instructions-Eintrag nötig, die Referenz reicht der KI als Kontext.

## Einmalige Einrichtung

### 1. Zentralen Ordner anlegen und befüllen

Einen Ordner an einer festen Stelle anlegen (z.B. `C:\dev\ai\skills`), dann das ZIP dort hinein
entpacken. Danach liegt in `C:\dev\ai\skills` pro Skill ein Unterordner mit `SKILL.md` darin
(`C:\dev\ai\skills\wizard\SKILL.md`, `C:\dev\ai\skills\tdd\SKILL.md`, …):

<DownloadAllButton />

### 2. Pro Projekt: `.ai-skills` verlinken

Im Projekt-Root, in der Kommandozeile (kein Administrator nötig, Junctions brauchen keine erhöhten
Rechte):

```
mklink /J .ai-skills C:\dev\ai\skills
```

`.ai-skills` gehört in die `.gitignore` (lokal oder projektweit): es ist ein persönlicher Verweis
auf deinen Rechner, kein Repo-Inhalt, den andere mitbekommen sollen.

## Skills aktualisieren

Neue oder geänderte Skills laden sich alle über denselben ZIP-Download nach: alten Inhalt im
zentralen Ordner überschreiben, fertig. Kein erneuter Symlink nötig, der zeigt schon auf den
richtigen Ort.

## Fehlerbehebung

Taucht `.ai-skills` in der `#`-Liste nicht auf, obwohl der Junction-Link existiert:

1. **Existiert die Datei wirklich?** Im Projekt-Root: `dir .ai-skills\<name>`, steht da
   `SKILL.md` drin?
2. **Blendet IntelliJ `.ai-skills` aus?** JetBrains-IDEs schließen Punkt-Ordner oft von der
   Indexierung aus, und was nicht indexiert ist, taucht auch in der `#`-Auswahl nicht auf. Check:
   **Settings → Editor → File Types → Ignored Files and Folders**, und im Project-Tool-Fenster per
   Rechtsklick auf `.ai-skills`, ob er als "Excluded" markiert ist.

## Für Kollegen

Diese zwei Schritte gelten pro Rechner, nicht pro Projekt: einmal einrichten, danach reicht in
jedem Projekt mit `.ai-skills`-Junction die `#`-Referenz im Chat. Wer mitmachen will, braucht nur
den ZIP-Download und den `mklink /J`-Befehl im jeweiligen Projekt-Root.
