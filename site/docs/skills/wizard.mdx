# wizard

<SkillHeader category="Standalone" githubPath="wizard" />

**Erzeugt ein interaktives Bash-Skript für Schritte, die nur ein Mensch ausführen kann** — Infrastruktur bereitstellen, Zugangsdaten oder CI-Secrets einrichten, ein unbekanntes Drittanbieter-Dashboard durchklicken, eine einmalige Migration fahren. Nicht für Schritte, die der Agent selbst erledigen könnte.

## Wann nutzen

- Ein Vorgang lässt sich nicht automatisieren, weil er zwingend einen Menschen braucht (klicken, kopieren, bestätigen) — aber der Vorgang selbst soll strukturiert und wiederholbar sein.

Die eigentliche UX (Fortschrittsanzeige, Bestätigungs-Gates, plattformübergreifendes URL-Öffnen, versteckte Secret-Eingabe, `.env`- und `gh secret`-Schreiben) ist bereits in `template.sh` gelöst — die Aufgabe dieses Skills ist nur, den Ablauf zu scopen und seine Stationen zu verfassen.

## Gut zu wissen

Ein Wizard ist **standardmäßig Wegwerfcode** für einen einzigen Lauf. Erst wenn der Nutzer einen wiederholbaren Einrichtungspfad will, wird er committet und aus der README verlinkt.
