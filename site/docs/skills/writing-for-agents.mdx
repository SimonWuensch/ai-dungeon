# writing-for-agents

<SkillHeader category="Standalone" invocation="model" githubPath="productivity/writing-for-agents" />

## Was ist `writing-for-agents`?

**Die Referenz zum Schreiben von allem, was ein Agent konsumiert** — ein Skill, ein `AGENTS.md`/`CLAUDE.md`, ein per Pointer erreichtes Dokument. Die Verpackung unterscheidet sich, das Schreiben nicht: dieselben Hebel machen jedes Dokument vorhersagbar.

## Wann brauche ich das?

- Beim Erstellen oder Bearbeiten eines Skills, oder beim Ändern von `AGENTS.md`/`CLAUDE.md`.

Material, das nur über einen **Context Pointer** erreicht wird, entkommt dem ständigen Context Load — zum Preis der einen Pointer-Zeile. Die **Information Hierarchy** ordnet Inhalte danach, wie unmittelbar der Agent sie braucht: Schritt im Dokument → Referenz im Dokument → ausgelagerte Referenz hinter einem Pointer.

## Gut zu wissen

**Leading Words** (ein kompakter, im Modell bereits vorgeprägter Begriff wie *tight* oder *fog of war*) verankern Verhalten in wenigen Tokens — eigene Wortschöpfungen funktionieren, kosten aber Definitions-Tokens, die ein bereits bekanntes Wort umsonst mitbringt.
